CHEZ WIEME — VERSION PRÉPARÉE POUR GITHUB PAGES

Adresse prévue :
https://touirwieme-blip.github.io/plat-d-etudiant/

1) Sur GitHub, ouvrez le dépôt plat-d-etudiant.
2) Cliquez sur Add file > Upload files.
3) Décompressez cette archive et téléversez le CONTENU du dossier,
   pas le dossier parent.
4) Faites Commit changes sur la branche main.
5) Ouvrez Settings > Pages.
6) Dans Build and deployment, choisissez Deploy from a branch.
7) Branche : main ; dossier : /(root) ; cliquez Save.
8) Attendez la publication, puis ouvrez l'adresse prévue ci-dessus.

GOOGLE :
- Après publication, ajoutez le site dans Google Search Console.
- Vérifiez la propriété avec la méthode proposée par Google.
- Envoyez le sitemap : sitemap.xml.
- L'indexation peut prendre plusieurs jours ou semaines. Elle n'est pas garantie.

À VÉRIFIER AVANT PUBLICATION :
- Les fichiers reçus ne contenaient pas les photos couscous.jpg,
  image-3.jpg et ojja.jpg. Ajoutez-les dans le dossier images.
- Les fichiers reçus ne contenaient pas connexion.html, inscription.html,
  panier.html ni commande.html, alors que le site contient des liens vers eux.
  Si ces pages existent déjà dans votre dépôt GitHub, gardez-les. Sinon,
  il faut les ajouter avant de considérer le site complet.
- Le numéro WhatsApp du site est vide dans script.js (CONTACT.whatsapp).
  Ajoutez votre numéro tunisien au format international sans + ni espaces
  pour activer les liens WhatsApp.
- Cette version conserve le fonctionnement prototype local décrit dans
  LISEZ-MOI.txt : comptes/commandes simulés dans le navigateur, pas de
  vraie base de données ni authentification sécurisée côté serveur.

IMPORTANT :

  paramétrage du domaine personnalisé sur GitHub Pages.
- Ne partagez jamais votre mot de passe GitHub ou vos codes de vérification.
